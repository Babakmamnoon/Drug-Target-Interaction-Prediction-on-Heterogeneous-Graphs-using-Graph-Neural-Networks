## Introduction

Predicting whether a small-molecule drug physically binds to a protein target — **drug–target interaction (DTI)** prediction — is a foundational problem in computational drug discovery. Experimentally characterizing DTI pairs is prohibitively slow and expensive: each New Molecular Entity (NME) approval costs approximately $1.8 billion and takes 9–12 years. High-throughput *in silico* screening of candidate drug–target pairs can dramatically accelerate this process by prioritizing the most promising candidates for wet-lab validation.

Classical DTI prediction methods rely on feature engineering — molecular fingerprints such as ECFP4 for drugs and hand-crafted descriptors such as pseudo-amino acid composition for proteins — fed into support vector machines or random forests. These approaches fail to capture structural hierarchy and are inherently limited by the information content of the chosen descriptors.

**Graph Neural Networks (GNNs)** represent drugs as molecular graphs where atoms are nodes and bonds are edges, learning structural representations end-to-end. When combined with sequence-based protein encoders and an explicit interaction modeling layer, GNNs achieve state-of-the-art performance on major DTI benchmarks. This project implements a complete, industry-grade heterogeneous GNN pipeline for binary DTI prediction on the **BioSNAP-DTI** benchmark dataset, following best practices established in *Nature Machine Intelligence*, *Bioinformatics*, and *ACS Omega*.

## Project Overview

This end-to-end pipeline covers:

- Automated data acquisition and curation from the **BioSNAP-DTI** benchmark (27,462 drug–target pairs)
- Comprehensive exploratory data analysis of the drug chemical space and protein sequence space
- **27-dimensional atom-level graph featurization** of drug molecules via RDKit
- **Multi-scale 1D CNN protein encoder** capturing local and semi-global sequence motifs
- **Bilinear attention interaction module** for explicit pairwise drug–target feature fusion
- Training with early stopping, gradient clipping, and ReduceLROnPlateau scheduling
- Full evaluation suite: AUROC, AUPRC, Accuracy, F1, Precision, Recall, MCC
- **5-fold stratified cross-validation** for unbiased performance estimation
- Decision threshold optimization analysis
- Benchmark comparison against six published DTI methods on the same dataset
- Metrics radar chart, ROC/PRC curves, confusion matrix, and molecule-level prediction visualization

## Dataset

**BioSNAP-DTI** (Zitnik et al., Stanford SNAP, 2018; pre-processed by Huang et al., *Bioinformatics*, 2021) is one of the most widely used benchmarks for binary DTI classification in the computational biology literature.

| Property | Value |
|---|---|
| Total DTI pairs | ~27,462 |
| Unique drugs | 4,510 |
| Unique protein targets | 2,181 |
| Positive interactions | ~13,830 (50%) |
| Negative interactions | ~13,632 (50%) |
| Drug representation | SMILES |
| Protein representation | Amino acid sequence |
| Source | DrugBank 5.0, Stanford SNAP MINER |
| Standard split | Train / Val / Test ≈ 70 / 10 / 20 % |

The dataset was derived from DrugBank 5.0 and includes drugs approved for use in the US market alongside their experimentally verified protein targets. Negative DTI pairs are generated by sampling from unobserved drug–target pairs, yielding a balanced binary classification benchmark.

The data is sourced directly from the **MolTrans GitHub repository** (Huang et al., 2021), which provides the standard pre-split CSV files used across all published comparisons.

**Cleaning steps applied:**
1. Removal of rows with missing SMILES, protein sequences, or labels
2. SMILES validation and canonicalization via RDKit
3. Protein sequence validation — only standard 20-letter amino acid alphabet accepted
4. Protein length capping at 1,200 amino acids (covers >95% of BioSNAP; prevents memory overflow)

## Methodology

### Drug Featurization — Molecular Graph

Each drug SMILES string is converted to a PyTorch Geometric `Data` object. The featurization uses 27-dimensional atom feature vectors and 6-dimensional bond feature vectors, consistent with the scheme validated in DrugBAN (Bai et al., 2023):

**Atom features (27 dimensions):**

| Feature | Encoding | Dim |
|---|---|---|
| Atom type | One-hot (13 types + other) | 13 |
| Hybridization | One-hot (SP, SP2, SP3, SP3D, SP3D2, other) | 6 |
| Aromaticity | Binary | 1 |
| Formal charge | Integer | 1 |
| Total H count | Integer | 1 |
| Ring membership | Binary | 1 |
| Chirality | One-hot (4 types) | 4 |

**Bond features (6 dimensions):** bond type (single/double/triple/aromatic), conjugation, ring membership — added in both directions for an undirected graph.

### Protein Featurization — 1D CNN Encoding

Each protein amino acid sequence is encoded as an integer tensor (vocabulary size 22, max length 1,200) and passed through a three-branch parallel 1D CNN with kernel sizes 3, 7, and 11. Adaptive max-pooling over each branch collapses the variable-length sequence to a fixed 256-dimensional protein embedding, capturing local dipeptide patterns, short-range motifs, and medium-range secondary structure signals simultaneously.

### Model Architecture — DTI-GNN

```
Drug SMILES                              Protein Sequence
     │                                         │
     ▼                                         ▼
[Input Projection]                    [Embedding Layer (128-dim)]
     │                                         │
[ResGCN Block × 3]             [Parallel CNN: kernel 3 + 7 + 11]
(BatchNorm + Residual)            (Adaptive Max Pool → concat)
     │                                         │
[Global Mean Pool]                    [BatchNorm + FC (256-dim)]
[Global Max Pool]                             │
[Concat → 256-dim drug emb]          [256-dim protein emb]
          │                                   │
          └──────────┬────────────────────────┘
                     ▼
          [Bilinear Attention Module]
          (pairwise drug–target gating → 256-dim)
                     │
          [MLP Classifier]
          (256 → 128 → 64 → 2)
          (BatchNorm + Dropout at each layer)
                     │
          [Binary DTI Prediction]
          (interacts / does not interact)
```

Key design decisions:
- **Residual connections** in all GCN blocks stabilize gradients across depth
- **Dual pooling** (mean + max concatenation) preserves both average and extremal atom signals
- **Bilinear attention** explicitly models pairwise drug–target feature interactions rather than naive concatenation, as validated in DrugBAN
- **Parallel CNN kernels** of different sizes capture protein motifs at multiple scales without additional parameters

Total trainable parameters: ~1.2M

### Training Strategy

| Hyperparameter | Value |
|---|---|
| Optimizer | Adam |
| Learning rate | 5 × 10⁻⁴ |
| Weight decay | 1 × 10⁻⁵ |
| Batch size | 64 |
| Max epochs | 50 |
| LR scheduler | ReduceLROnPlateau (factor=0.5, patience=5, mode=max AUROC) |
| Early stopping | Patience = 10 epochs (Val AUROC) |
| Loss function | Cross-Entropy |
| Gradient clipping | Max norm = 1.0 |
| Cross-validation | 5-fold stratified (CV epochs: 20) |
| Random seed | 42 |

### Literature Benchmark Comparison

| Model | Architecture | AUROC | AUPRC | Accuracy | F1 |
|---|---|---|---|---|---|
| **This DTI-GNN** | GCN + CNN + Bilinear Attn | **~0.95** | **~0.95** | **~0.88** | **~0.88** |

## Installation & Usage

### Run on Google Colab (Recommended)

Click the **Open in Colab** badge at the top of this README. All dependencies install automatically in the first cell. A GPU runtime (Runtime → Change runtime type → T4 GPU) is strongly recommended — training on BioSNAP-DTI takes approximately 30–60 minutes on GPU vs several hours on CPU.

### Run Locally

**Requirements:** Python 3.10+, CUDA-capable GPU (recommended)

```bash
# Clone the repository
git clone https://github.com/<your-username>/dti-gnn-biosnap.git
cd dti-gnn-biosnap

# Install dependencies
pip install rdkit torch torch-geometric pandas numpy scikit-learn \
            matplotlib seaborn requests tqdm scipy pillow

# Launch the notebook
jupyter notebook DTI_GNN_BioSNAP.ipynb
```

> The dataset downloads automatically from the MolTrans GitHub repository at runtime — no manual download required.
